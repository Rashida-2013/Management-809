# College Management System (MERN)

Backend (Express + MongoDB):
  cd backend && npm install && npm start      -> http://localhost:5000
Frontend (React + Vite):
  cd frontend && npm install && npm run dev   -> http://localhost:5173

MongoDB must be running locally (or set MONGO_URI in backend/.env).
Demo logins: admin/admin123, faculty1/faculty123, student1/student123
Customize: frontend/src/config.js and frontend/public/logo.png
